01 / CONTEXT & CHALLENGES

Why Modern Fleets Need Mission Control

Addressing data fragmentation, reactive monitoring, and lack of real-time operational sync.

DRONE FLEET AI
MISSION CONTROL
PROBLEM 01

Fragmented Fleet Information

Airframe specs, battery health, pilot logs, and maintenance records are typically spread across disconnected spreadsheets and silos, delaying critical dispatch decisions.

PROBLEM 02

Reactive Telemetry & Latency

Traditional polling dashboards miss rapid altitude or ESC thermal drops. Without low-latency WebSocket downlinks, operators detect airframe anomalies too late.

PROBLEM 03

Operational Desynchronization

Changes made in fleet management (e.g. status or battery adjustments) fail to propagate to active mission control rooms, leading to hazardous dispatch errors.

Core Project Objectives

• Centralize Fleet Lifecycle: Consolidate registration, missions, maintenance, and alerts into one dark-themed mission control interface.
• Real-Time Synchronization: Instant bidirectional updates between Fleet Management and Live Telemetry Streams via MongoDB & WebSockets.
• AI-Powered Assistance: Integrate Google Gemini AI to provide natural language diagnostics, readiness checks, and executive reporting.

Frontend Layer

React 18 SPA

• Framework: React 18, React Router v6
• UI & Styling: Dark glassmorphism, responsive grid layout
• Charts: Recharts (Oscilloscope, Area, Donut charts)
• Iconography: Lucide React
• Networking: Axios + native WebSocket with auto-reconnect

Backend & API Layer

FastAPI (Python)

• Framework: FastAPI (Async ASGI, Python 3.11+)
• Validation: Pydantic v2 schemas
• Security: JWT Bearer Authentication (passlib, bcrypt)
• Real-Time: Native WebSocket handler (/ws/telemetry)
• Reporting: Pure Python %PDF-1.4 binary engine (zero DLL lag)

Database & AI Layer

MongoDB + Gemini AI

• Primary DB: MongoDB (Async Motor / PyMongo driver)
• Fallback: AsyncLocalDatabase with JSON persistence
• Collections: drones, missions, telemetry, maintenance, alerts, users
• AI Assistant: Google Gemini Pro API integration
• Deployment: Render Web Service + Vercel Static Edge

Deployment Architecture: The backend is hosted as an asynchronous web service on Render, while the compiled React application is deployed with edge static rewrites on Vercel, ensuring 99.9% uptime and global low-latency CDN delivery.

🛰️ 6 Avionics Gauges

• Altitude: MSL airborne clearance (m)
• Ground Speed: Airborne velocity vector (m/s)
• Battery Level: LiPo 6S smart pack charge (%)
• ESC Temp: Optimal thermal monitoring (°C)
• GNSS Signal: 14 Satellite lock accuracy (%)
• Downlink Status: 24ms low-latency link

🎯 Airspace Tactical Radar

• 5.0 km Geofence Radius: Concentric tactical range rings.
• Dynamic Marker: Visual beacon shifts to in-flight sector coordinates and pulses during active missions.
• Base Station Origin: Centered reference coordinates for autonomous return-to-base (RTL).

📈 Dual-Trace Oscilloscope

• Real-Time Graph: Live streaming Recharts trace.
• Cyan Line: Dynamic altitude variations (m).
• Green Line: Ground speed transitions (m/s).
• Historical Buffer: 20-point sliding window showing instantaneous changes upon status transition.

Key Engineering Feat: Bi-Directional Synchronized State

When an operator updates a drone's status (Available ➔ In Flight) or edits its battery percentage in Drone Fleet Management, the update is committed to MongoDB and immediately transmitted across the active WebSocket stream. Cruising physics (105m–145m altitude, 12–17.5 m/s speed) engage instantly without mock buttons on the telemetry screen.
